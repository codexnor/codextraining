Hvis du har et GitHub Pages-repository fra før:
1. Legg inn / erstatt index.html.
2. Last opp de fire støttefilene i samme mappe som index.html.
3. Åpne GitHub Pages-adressen i Safari (iPhone) eller Chrome (Android).
4. På iPhone: Del -> Legg til på Hjem-skjermen. På Android: Meny -> Installer app.
5. Opprett egen profil for hver bruker. Trening lagres lokalt for den enkelte telefonen.

Appen fungerer også med bare index.html når den hostes på nett, men uten
støttefilene blir ikke frakoblet/offline installasjon som PWA tilgjengelig.

SIKKERHETSKOPI
Innstillinger -> Sikkerhetskopi -> Eksporter JSON.
Lagre filen et trygt sted. Den inneholder alle profiler og treningsøkter.
Ved import erstattes lokale data etter bekreftelse.

MERK: Det er ingen automatisk synkronisering mellom telefoner.
